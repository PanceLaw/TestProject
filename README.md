# Тестовое задание QA: банковские продукты

## Описание

В проекте реализована архитектура банковских продуктов:

- дебетовая карта;
- валютная дебетовая карта;
- кредитная карта;
- вклад.

Общие параметры банковского продукта:

- название;
- валюта;
- баланс.

Денежные значения представлены value object `Money`. Он хранит сумму и валюту вместе, поэтому нельзя случайно сложить или списать деньги в разных валютах.

Внутри `Money` для суммы используется `BigDecimal`, потому что денежные расчеты должны быть точными.

## Архитектура

Базовый контракт любого банковского продукта описан интерфейсом `BankProduct`.

Общее поведение разделено на небольшие интерфейсы:

- `Replenishable` - продукт можно пополнять;
- `Withdrawable` - с продукта можно списывать средства;
- `ClosableProduct` - продукт можно закрыть.

Общие поля и базовая валидация вынесены в `AbstractBankProduct`.

Карты наследуются от `AbstractCard`, где реализовано общее поведение пополнения. Конкретная логика списания находится в классах-наследниках, потому что дебетовая и кредитная карты работают по-разному.

## Money

`Money` содержит:

- `amount` - сумма;
- `currency` - валюта.

`Money` отвечает за:

- запрет отрицательных сумм;
- нормализацию суммы до двух знаков после запятой;
- проверку валюты на `null`;
- сложение денежных сумм;
- вычитание денежных сумм;
- сравнение денежных сумм;
- запрет операций между разными валютами.

Если попытаться выполнить операцию между разными валютами, например `RUB` и `USD`, будет выброшено `CurrencyMismatchException`.

## Реализованные продукты

### DebitCard

Дебетовая карта поддерживает:

- пополнение;
- списание;
- запрос баланса.

Списание невозможно, если на карте недостаточно средств.

### CurrencyDebitCard

Валютная дебетовая карта наследует поведение обычной дебетовой карты. Валюта хранится внутри `Money`, например `new Money(amount, Currency.USD)` или `new Money(amount, Currency.EUR)`. Валюта `RUB` для валютной карты запрещена.

### CreditCard

Кредитная карта поддерживает:

- пополнение;
- списание;
- запрос баланса;
- запрос задолженности;
- запрос процентной ставки;
- запрос кредитного лимита;
- запрос доступных средств.

При списании сначала расходуется собственный баланс. Если его недостаточно, недостающая сумма переходит в задолженность. Списание невозможно, если операция превышает кредитный лимит.

При пополнении кредитной карты сначала погашается задолженность. Остаток суммы после погашения увеличивает баланс.

### Deposit

Вклад поддерживает:

- пополнение;
- запрос баланса;
- закрытие.

При закрытии вклад возвращает сумму выплаты, переводит баланс в `0` и получает статус закрытого продукта. Пополнение закрытого вклада и повторное закрытие запрещены.

## Исключения

В проекте используются доменные исключения:

- `InvalidAmountException` - некорректная сумма;
- `InsufficientFundsException` - недостаточно средств или превышен кредитный лимит;
- `ProductClosedException` - операция невозможна, потому что продукт закрыт;
- `CurrencyMismatchException` - операция невозможна из-за разных валют.

Сообщения исключений написаны транслитом, чтобы они стабильно отображались в консоли и логах.

## Расширяемость

Архитектура рассчитана на добавление новых продуктов без изменения существующих классов.

Например, новый накопительный счет может наследоваться от `AbstractBankProduct` и реализовать только нужные интерфейсы:

```java
public class SavingsAccount extends AbstractBankProduct implements Replenishable, Withdrawable {
    // логика нового продукта
}
```

Если новый продукт нельзя пополнять, он просто не реализует `Replenishable`. Если продукт нельзя закрывать, он не реализует `ClosableProduct`.

## Тесты

Unit-тесты написаны на JUnit 5.

Покрыты сценарии:

- создание банковских продуктов;
- пополнение;
- списание;
- недостаток средств;
- превышение кредитного лимита;
- расчет задолженности кредитной карты;
- расчет доступных средств кредитной карты;
- закрытие вклада с возвратом суммы выплаты;
- запрет пополнения закрытого вклада;
- валидация названия, валюты, денежных сумм и сумм операций;
- запрет операций между разными валютами;
- параметризованные проверки некорректных значений.

## Запуск

Запустить тесты можно командой:

```bash
mvn test
```
